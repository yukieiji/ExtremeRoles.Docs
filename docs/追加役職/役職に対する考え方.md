# 役職に対する考え方

ExtremeRoles（ExR）における役職設計の基本的な考え方と、新しい役職案をご提案・ご検討いただく際の基準について記載しています。新しい役職案を提案・検討する際は、本ページの内容を事前に必ずご確認ください。

---

## ExRにおける役職設計の基本的な考え方

ExR自体の役職に対する考え方として、以下のプロセスと基準を最優先としています。

1. **コンセプトを第一に考える**
   - 「この役職はどういった役職なのか？」を一言で簡潔に表せる明確なコンセプトが存在するかを最も重視します。
2. **コンセプトと能力/陣営が一致しているかを詰める**
   - 設計したコンセプトに対し、割り当てる陣営や能力が矛盾なく一致しているかを詰めていきます。単に「面白い」「便利」という理由だけではなく、その陣営としての勝利条件や役割に結びついているかが重要です。

新しい役職提案の評価・検討にあたっては、下記に掲載するレビュープロンプトに基づき検証を行います。

---

## レビュープロンプト

```
提示された役職案について、作者に配慮せず、問題点・矛盾・既存役職との競合を積極的に探してください。 「面白そう」「一応使える」といった理由だけで肯定せず、役職として成立しているかを厳しく検証してください。(クロス的に敵対的レビューをすること)

レビュー時は必ず以下のWikiを参照してください。

ExtremeRoles Wiki: https://yukieiji.github.io/ExtremeRoles.Docs/

レビューする観点
1. 役職のコンセプト
この役職はどういった役職なのか？を一言で表せれるか？

2. 陣営と能力が一致しているか
「この陣営だからこそ、この能力である意味があるか」を厳しく確認してください。 特に他の陣営へのストレスに関しては極端に与えすぎると不快な思いが発生しがちなので注意です

クルー
能力がクルー陣営の勝利(タスク/追放)に結びついているか確認してください。

特に、

インポスターを発見するための推理材料を与える
インポスターの行動を制限する
インポスターにリスクやストレスを与える
クルー側の情報収集・推理を補助する
などの方向に能力が機能しているかを見てください。

単に「便利」「強い」だけで、クルーの勝利に結びついていない能力は問題視してください。

逆に、能力によって推理する必要がなくなり、単純に答えを得られてしまう場合も問題視してください。

インポスター
能力がインポスター陣営の勝利(サボタージュ/他陣営の排除)に結びついているか確認してください。

特に、

キル能力の強化
キルを通しやすくする
クルーの情報を遮断する
アリバイや証拠を操作する
クルーの推理を妨害する
誤った推理を誘発する
インポスターの行動を補助する
などの方向に機能しているか確認してください。

「能力自体は面白いが、インポスターが勝つためには特に役立たない」という能力は厳しく指摘してください。

ニュートラル
能力によって、本人の勝利条件に近づける構造になっているか確認してください。

勝利条件は必須
能力を使うことで勝利条件を達成しやすくなるか
能力を利用して他陣営を自分の勝利に利用できるか
能力が勝利条件と直接的に結びついているか
を確認してください。

能力だけを見ると強力でも、勝利条件との関係が薄い場合は問題視してください。

また、単に特殊能力を持っただけのクルー・インポスターのような「別陣営」になっていないかも確認してください。 ニュートラルとして独自の勝利条件・目的と能力が噛み合っているかを重視してください。

リベラル
能力によってリベラル陣営としての勝利に近づけるか確認してください。

特に、

資金を獲得できる
資金を利用して有利になる
経済的なアドバンテージを得られる
など、リベラル陣営としての特徴と能力が結びついているかを確認してください。

リベラルとしての能力/勝利条件/資金システムとの関係が薄く、他陣営でも成立する能力になっていないかも確認してください。

3. 能力がある程度の説明で理解できるか
「プレイヤーは作者が思っているほど賢くない」ことを前提にしてください。

名前から想像される役割と能力が一致しているか 能力説明を読んだプレイヤーが、できるだけ短い説明で仕様を理解できるかを評価してください。

最低限、

何ができるのか
いつ使えるのか
誰に使えるのか
何が起こるのか
何をすると有利なのか
勝利条件とどう関係するのか
が理解できる必要があります。

特に以下を問題視してください。

条件が多すぎる
例外が多い
条件の入れ子が多い(Aをやってた結果B、BじゃないとCはNG)
能力同士の相互作用を大量に覚える必要がある
説明文だけでは挙動を理解できない
作者には明白だが初見プレイヤーには分からない
一見簡単だが、実際には複雑
ゲーム中に覚えておくべき情報が多すぎる
単に文章が長いかではなく、プレイヤーが実際に覚えて運用できるかを評価してください。

4. 同名・同能力・既存役職の上位互換になっていないか
ExtremeRoles　Wikiに存在する既存役職・陣営・能力・役職分類を確認し、提示された役職と比較してください。

同名・類似名称
同名の役職が存在しないか
極めて近い名前の役職が存在しないか
同能力
既存役職とほぼ同じ能力ではないか
既存役職の能力を少し変更しただけではないか
「既存役職＋追加能力」になっていないか
上位互換
既存役職と同じ役割を持ちながら、

クールタイムが短い
使用回数が多い
射程が長い
対象が広い
デメリットがない
追加能力まで持っている
既存役職より汎用性が高い
などによって、単純な上位互換になっていないか確認してください。

既存役職をA、この役職をBとした場合、

「Aを使う理由がなく、Bを使った方が常に得」

となるなら、明確に問題として指摘してください。

ただし、上位能力だから必ず問題というわけではありません。

以下のような明確な制約・棲み分けが存在する場合は許容してください。

特定条件下でのみ強い
覚醒などの条件が必要
覚醒前は弱い
使用回数が少ない
大きなリスクやデメリットがある
特定の状況でしか機能しない
他の能力との組み合わせが必要
勝利条件が異なる
操作・判断難易度が高い
既存役職とは用途が明確に異なる
つまり、

「単純な上位互換」なのか、「制約によって差別化された派生・上位能力」なのか

を区別してください。

敵対的レビューの原則
レビューでは、役職の欠点を探すことを優先してください。 過度な忖度や尊敬、肯定は役に立ちません

例えば、

「この能力は本当にこの陣営に必要なのか」
「既存役職で代用できないか」
「結局○○の上位互換ではないか」
「能力を説明するための条件が多すぎないか」
「この能力と勝利条件が噛み合っているか」
「役職名と実際の能力が一致しているか」
「既存役職との差別化は本当に成立しているか」
といった視点から厳しく検証してください。

ただし、根拠のない難癖は禁止です。

問題を指摘する場合は、必ず 「なぜ問題なのか」 「どの既存役職・仕様と競合しているのか」 「どの条件で問題になるのか」 を具体的に説明してください。

逆に、調査した結果として問題がない場合は、無理に問題を作らず「この点は問題なし」としてください。

レビュー形式は固定せず、役職ごとに必要な観点を選んで自由に構成してください。

##　ExtremeRoles本体の仕様

能力ボタンは一つのみ
複数持たせたい場合はホイールスクロールによる切り替えが発生する
能力ボタンのクールタイムはデフォルト30秒
プレイヤーの切り替え設定によって切り替えれるが、デフォルト値を設定できません
ボタンの種類
以下を組み合わせることが可能
発動後一定時間アクティブになるアクティブボタン
発動後チャージを行えるボタン
使い回せるボタン
使用回数制限
ちょっと特殊なことをやりたい場合は以下のDiscussionを参照
https://github.com/yukieiji/ExtremeRoles/discussions/87
それ以外はWikiを参照
Wikiに記載されていない仕様を、既存仕様として推測・断定しないでください。
必要な情報がWikiから確認できない場合は、その旨を明記してください。

役職追加要求テンプレート
基本的にはこれを埋めるように構築する事、名前と色は未定でも可

陣営/Team
役職名/RoleName
このカッコ内に任意で役職の説明を1文で
"役職の色 / Role color"
インポスターであればインポスターレッド、リベラルならリベラルイエロー
役職の説明 / Role description
勝利条件等がある場合はここに記載
役職の能力 / Role ability
第三陣営以外は能力に関しての説明だけではなく、その能力の発動コストやリスク等も記載して下さい / Except for the third team, please include not only a description of the ability, but also the cost and risk of activating that ability.
他陣営への影響 / Effect on other teams
その役職に対してどう気づけるか、対抗手段はあるか、付け入る隙があるか
```
